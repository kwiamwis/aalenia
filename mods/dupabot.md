# DupaBot
DupaBot is a JavaScript application which integrates Discord and PoT community servers, making heavy use of the features added in the Aalenian Utilities mod. 

This community uses the latest official version whose information, Terms of Service, and Privacy Policy exists at the [DupaBot Application Directory Page](https://discord.com/application-directory/1269438810316341299). The community Discord functions as it's support server.

The official version of DupaBot is currently not functional for other communities. Any community may deploy the open-source docker image once the application is complete.
