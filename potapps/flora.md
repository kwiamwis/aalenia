# Aalenian Flora
Aalenian Flora adds multiple types of plants and fungi to Path of Titans as creator mode objects, accessible in the creator mode menu.
## Interactable Flora
* Amanita cluster - eating gives base game mushroom effect
* Boletus cluster - eating gives base game mushroom effect
* Hydrangea (pink and blue) patches - eating gives cyanogenic glycoside effect, nullifying health regen and increasing stamina regen due to the ensuing panic
* Nymphaea group - eating replenishes thirst
* Achilla (purple and yellow) patches
* Oxalis patch
* Canna patch
## Inexhaustible Food Sources
* Canna aeterna - forever flowers
* Taxus aeterna - forever berries
## Non-Interactable Flora
* Giant Amanita (fungi) and Boletus (fungi)
* Large Alnus (alder) trees whose branches are landable
## Installation
Add the following line of code to your server's GameUserSettings.ini
```ini
EnabledMods=(ModSku="UGC_M_5XN7VDP7PZ_SK", BuildSku="release")
```
